# Свой голос

Мобильное приложение для самостоятельной практики: читаешь короткое задание, повторяешь, сохраняешь наблюдение. Без регистрации внутри приложения, платных API и внешних библиотек.

## Что работает

- 44 занятия: свободная речь — 12 × 18 минут, вокал — 12 × 9 минут, клавиши — 12 × 6 минут, музыкальные эскизы — 8 × 5 минут. Время упражнений указано без времени озвучивания инструкции.
- Один экран с одним упражнением, ручной переход, таймер, восстановление текущего шага.
- Режим слушания: синтез речи телефона читает задание, затем идёт пауза для практики и переход к следующему шагу. В вокальных упражнениях перед паузой звучит пример. Озвучивание зависит от поддержки Web Speech API и русского голоса на устройстве.
- Звуковые примеры, изменение высоты на ±12 полутонов, экранная клавиатура и аккорды, метроном.
- 8-шаговый редактор ударных: один такт 4/4, шаг = восьмая. Сохранение и открытие эскиза JSON.
- Запись дублей до 5 минут в IndexedDB, воспроизведение, отдельное скачивание каждого дубля.
- История, личная оценка лёгкости, заметки, объединение резервных копий прогресса.
- PWA, относительные пути для размещения в подпапке GitHub Pages, офлайн-копия приложения после загрузки.

Учебная база: адаптированы ранее созданные «Программа свободного голоса», «Клавиши без каши» и «Фортепиано: от нуля до уверенной игры». Вокальные занятия и мастерская добавлены для этой версии. Имя, профессия и модель личного инструмента исключены из поставляемых текстов. Примеры нейтральны. Существующие записи и заметки пользователей при обновлении не удаляются. Предпочтение — естественной речи, ясному смыслу и практике, без искусственного баса.

## Запуск

Нужны только Python 3 для локального просмотра и Node.js для проверки:

```sh
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Для записи микрофона и PWA на телефоне нужен HTTPS-хостинг. Само открытие HTML через файловый менеджер не заменяет размещение на HTTPS.

```sh
node verify.js
```

Учебные данные редактируются в `make_lessons.py`; после изменений выполнить `python3 make_lessons.py`. Интерфейс и логика — `dist/app.js`, оформление — `dist/style.css`.

## GitHub Pages

1. Поместить проект в отдельный репозиторий.
2. В Settings → Pages выбрать Source: GitHub Actions. Доступность Pages зависит от тарифа и видимости репозитория; публичная публикация не включается этим README.
3. В Actions запустить `Publish to GitHub Pages` вручную. Workflow публикует содержимое `dist`, без сборки.
4. Открыть адрес, который вернёт успешный workflow.

Официальная схема: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Для другого статического HTTPS-хостинга достаточно папки `dist`.

## Телефон и данные

Открыть ссылку в Chrome на Android. При наличии пункта установки выбрать «Добавить на главный экран» / «Установить приложение». Наличие диалога установки зависит от браузера. Включены PNG-значки 192×192 и 512×512, отдельный maskable-значок и страница с инструкциями установки.

Записи, заметки и прогресс не отправляются серверу. Системный синтез речи может использовать голосовые сервисы устройства; наличие офлайн-голоса зависит от телефона. Для русского озвучивания проверить настройки синтеза речи Android.

Данные принадлежат конкретному браузеру и адресу сайта. Переход на другой хостинг не переносит их автоматически: скачать резервную копию, затем восстановить. Аудиодубли скачать отдельно. Очистка браузера может удалить локальные данные.

## Режим в дороге

Если пользователь за рулём, читать и управлять телефоном в движении нельзя: запустить слушание до поездки. Приложение приостанавливает занятие и запись при сворачивании; гарантированного фонового воспроизведения нет. При доступном Screen Wake Lock режим слушания запрашивает удержание включённого экрана. При ошибке озвучивания таймер не начинает отсчёт молча.

Пение — на удобной высоте, небольшой громкости, с отдыхом. При боли, першении или осиплости практику прекращают. Клавиатурную технику и две руки учат на инструменте; экранная клавиатура помогает со звуком и расположением нот.

## Границы первой версии

Нет автоматической оценки тембра, высоты спетой ноты или дикции; оценки в истории вводит пользователь. Нет подключения MIDI, синхронизации между устройствами, аудиоэкспорта бита и многодорожечной записи. Музыкальная мастерская создаёт эскизы; полноценную аранжировку можно продолжить в FL Studio.

В первой версии проверены в браузере: путь занятия от старта до сохранения, таймер/пауза, восстановление шага после перезагрузки, заметка и прогресс, ноты/аккорды/управление битом, интерфейс при ширине 390 px. В проверочном браузере синтез речи завершился ошибкой, корректно показана подсказка; звучание русского голоса и реальная запись микрофона на телефоне требуют проверки на устройстве. Приложение не включает тестовые пользовательские данные.

## Перенос в новый репозиторий

Переносить снимок файлов `dist/`, `make_lessons.py`, `verify.js`, `README.md` и `.github/workflows/pages.yml`. Каталог `.openai` относится к текущему хостингу; он не нужен для GitHub Pages. Не переносить старую историю Git, личные аудиофайлы и экспортированные пользовательские заметки. Установка на GitHub Pages независима от входа через ChatGPT на текущей приватной ссылке.
