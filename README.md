# Свой голос

Мобильное приложение для самостоятельной практики: читаешь короткое задание, повторяешь, сохраняешь наблюдение. Без регистрации внутри приложения, платных API и внешних библиотек.

## Программа 2.0

112 занятий: речь — 24, вокал — 24, клавиши — 48, музыка — 16. Сохранены ID 44 прежних занятий, их MP3 и пользовательская история. 68 новых занятий текстовые; музыкальные примеры синтезируются локально. Генерация новой озвучки отложена по решению пользователя.

У каждого занятия есть наблюдаемая цель, критерии самостоятельной проверки и ссылка на предыдущий шаг маршрута. Пользователь отдельно отмечает практику руками и выполнение критериев. Нажатие «дальше» не означает освоения. `completed` сохраняет прежнюю историю практики, `mastered` — новые отметки по критериям; старые результаты автоматически в них не переводятся. Обе части включены в резервную копию.

Главная показывает одно сегодняшнее задание. План: понедельник — речь; вторник — клавиши; среда — вокал; четверг — клавиши; пятница — речь/вокал с чередованием недель от первого открытия маршрута; суббота — клавиши и музыка; воскресенье — отдых или добровольный повтор. Даты и дни берутся с устройства пользователя.

Внутри четырёх блоков (основа, управление, применение, самостоятельность) находятся соответственно по 6 речевых, 6 вокальных, 12 клавишных и 4 музыкальных урока. Уроки перегруппированы по содержанию, ID и аудиотексты сохранены. Следующий блок рекомендуется только после освоения всех навыков текущего во всех направлениях; уже освоенное направление получает повтор, пока остальные догоняют. Через «Курсы» можно открыть любой урок.

Маршрут реализован в `dist/planner.js`. Сохранённая практика закрывает слот дня, но не означает освоения навыка; чтение инструментального урока без практики слот не закрывает. Субботние задания выполняются по очереди. Пропуск сохраняет только текущее задание (или оставшуюся часть субботней пары), без накопления списка долгов. Перенос на завтра сохраняет те же ID; его можно отменить. После завершения перенесённого занятия новые задания в этот же день не добавляются. Свободная практика другого урока не закрывает назначенную задачу.

Календарь входит в резервную копию (`state.plan`); старые копии без него остаются совместимыми. Импорт копии с календарём восстанавливает её маршрут. Старые пользовательские занятия и освоенные навыки не удаляются. Это последовательность правил и самооценка, без автоматической диагностики или адаптивного ИИ.

Новые учебные данные находятся в `curriculum.py`, вызываемом из `make_lessons.py`. В клавишах добавлены обе руки, ритм, начальное чтение нот на бумаге, гаммы, слуховые задания, аккомпанемент, авторские миниатюры и контроль. Для полноценной проверки техники полезен педагог. Программа не присваивает уровни ABRSM/Trinity и не является их официальным курсом.

Источники принципов:
- ABRSM, практические компоненты: https://www.abrsm.org/en-gb/piano
- Trinity, исполнение и supporting tests: https://www.trinitycollege.com/qualifications/music/grade-exams/about
- NIDCD, удобное использование и отдых голоса: https://www.nidcd.nih.gov/health/taking-care-your-voice

## Что работает

- Начальная озвученная часть — 44 занятия: свободная речь — 12 × 18 минут, вокал — 12 × 9 минут, клавиши — 12 × 6 минут, музыкальные эскизы — 8 × 5 минут. Время упражнений указано без времени озвучивания инструкции.
- Один экран с одним упражнением, ручной переход, таймер, восстановление текущего шага.
- Режим слушания: готовая русская нейроозвучка читает задание, затем идёт пауза для практики и переход к следующему шагу. В вокальных упражнениях перед паузой звучит пример. Все 240 шагов начальной части используют 107 уникальных MP3-записей из папки `dist/audio`; временных внешних ссылок в приложении нет.
- Звуковые примеры, изменение высоты на ±12 полутонов, экранная клавиатура и аккорды, метроном.
- 8-шаговый редактор ударных: один такт 4/4, шаг = восьмая. Сохранение и открытие эскиза JSON.
- Запись дублей до 5 минут в IndexedDB, воспроизведение, отдельное скачивание каждого дубля.
- История, личная оценка лёгкости, заметки, объединение резервных копий прогресса.
- PWA, относительные пути для размещения в подпапке GitHub Pages, офлайн-копия приложения после загрузки.

Учебная база: адаптированы ранее созданные «Программа свободного голоса», «Клавиши без каши» и «Фортепиано: от нуля до уверенной игры». Вокальные занятия и мастерская добавлены для этой версии. Имя, профессия и модель личного инструмента исключены из поставляемых текстов. Примеры нейтральны. Существующие записи и заметки пользователей при обновлении не удаляются. Предпочтение — естественной речи, ясному смыслу и практике, без искусственного баса.

## Запуск

Нужны только Python 3 для локального просмотра и Node.js для проверки:

```sh
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Для записи микрофона и PWA на телефоне нужен HTTPS-хостинг. Само открытие HTML через файловый менеджер не заменяет размещение на HTTPS.

```sh
node verify.js
```

Учебные данные редактируются в `make_lessons.py` и `curriculum.py`; после изменений выполнить `python3 make_lessons.py`. Интерфейс и логика — `dist/app.js`, оформление — `dist/style.css`.

## GitHub Pages

1. Поместить проект в отдельный репозиторий.
2. В Settings → Pages выбрать Source: GitHub Actions. Доступность Pages зависит от тарифа и видимости репозитория; публичная публикация не включается этим README.
3. В Actions запустить `Publish to GitHub Pages` вручную. Workflow публикует содержимое `dist`, без сборки.
4. Открыть адрес, который вернёт успешный workflow.

Официальная схема: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Для другого статического HTTPS-хостинга достаточно папки `dist`.

## Телефон и данные

Открыть ссылку в Chrome на Android. При наличии пункта установки выбрать «Добавить на главный экран» / «Установить приложение». Наличие диалога установки зависит от браузера. Включены PNG-значки 192×192 и 512×512, отдельный maskable-значок и страница с инструкциями установки.

Записи, заметки и прогресс не отправляются серверу. Озвучивание использует готовые MP3-файлы на том же адресе, что и приложение. Кнопка «Сохранить голос для поездки» загружает записи выбранного занятия в отдельный офлайн-кеш. Само открытие приложения не скачивает озвучку всех уроков.

Данные принадлежат конкретному браузеру и адресу сайта. Переход на другой хостинг не переносит их автоматически: скачать резервную копию, затем восстановить. Аудиодубли скачать отдельно. Очистка браузера может удалить локальные данные.

## Режим в дороге

Если пользователь за рулём, читать и управлять телефоном в движении нельзя: запустить слушание до поездки. Приложение приостанавливает занятие и запись при сворачивании; гарантированного фонового воспроизведения нет. При доступном Screen Wake Lock режим слушания запрашивает удержание включённого экрана. При ошибке озвучивания таймер не начинает отсчёт молча.

Пение — на удобной высоте, небольшой громкости, с отдыхом. При боли, першении или осиплости практику прекращают. Клавиатурную технику и две руки учат на инструменте; экранная клавиатура помогает со звуком и расположением нот.

## Границы первой версии

Нет автоматической оценки тембра, высоты спетой ноты или дикции; оценки в истории вводит пользователь. Нет подключения MIDI, синхронизации между устройствами, аудиоэкспорта бита и многодорожечной записи. Музыкальная мастерская создаёт эскизы; полноценную аранжировку можно продолжить в FL Studio.

В первой версии проверены в браузере: путь занятия от старта до сохранения, таймер/пауза, восстановление шага после перезагрузки, заметка и прогресс, ноты/аккорды/управление битом, интерфейс при ширине 390 px. В проверочном браузере синтез речи завершился ошибкой, корректно показана подсказка; звучание русского голоса и реальная запись микрофона на телефоне требуют проверки на устройстве. Приложение не включает тестовые пользовательские данные.

## Перенос в новый репозиторий

Переносить снимок файлов `dist/`, `make_lessons.py`, `verify.js`, `README.md` и `.github/workflows/pages.yml`. Каталог `.openai` относится к текущему хостингу; он не нужен для GitHub Pages. Не переносить старую историю Git, личные аудиофайлы и экспортированные пользовательские заметки. Установка на GitHub Pages независима от входа через ChatGPT на текущей приватной ссылке.


## Нейроозвучка

Голос создан через AI Voice Generator, стиль `normal`. Генерировались только общедоступные инструкции, без пользовательских записей. Аудиофайлы находятся в репозитории и публикуются вместе с приложением. `dist/voices.js` сопоставляет шаги и файлы; одинаковые инструкции используют одну запись. Источники генерации и контрольные длительности: `voice-sources.json`.

Озвучка запускается нажатием пользователя. Таймер начинается после `ended`, затем при необходимости после музыкального примера. Пауза, смена шага и уход со страницы отменяют проигрывание. При ошибке загрузки таймер не запускается. Для офлайн-озвучки заранее сохранить нужное занятие. Обновление кеша приложения сохраняет прогресс, записи и кеш голоса.

Проверки: `node verify.js` и `node verify-voice.js`. Push в `main` автоматически публикует папку `dist` через GitHub Pages.

Проверка маршрута: `node verify-plan.js` — пятничное чередование, перенос, пропуски без долгов, два субботних задания, воскресенье, границы блоков и восстановление календаря.

## Пианино и аккорды

В «Практике» доступны 12 основных тональностей × 14 типов аккордов (168 сочетаний): мажор, минор, 7, maj7, m7, sus2, sus4, dim, aug, 6, m6, add9, dim7, m7♭5. Первое и второе обращения, совместная игра или перебор, состав аккорда с корректными названиями нот. Октава экранной клавиатуры переключается; касание удерживает звук до отпускания, максимум семь секунд. Все прежние уроки и сохранения совместимы.

Звук — девять локальных записей Salamander Grand Piano (Alexander Holm, CC BY 3.0), транспонирование ближайшей записи, естественное затухание и отпускание клавиши. Файлы под `dist/piano/` включены в офлайн-копию; во время работы приложение не обращается к внешней библиотеке звуков. При первой сетевой загрузке нужно дождаться готовности звука. Атрибуция и изменения указаны в `dist/piano/ATTRIBUTION.txt`, исходный текст лицензии — `SOURCE-LICENSE.txt`; ссылки доступны в справке приложения. Это компактный сэмплер с одним слоем динамики, не полная библиотека рояля.

Главная и экран урока сокращены: расписание, блоки, проверка и справочные пояснения свёрнуты; текст заданий и примеров сохранён. `node verify-music.js` проверяет состав всех аккордов и обращений, названия нот, загрузку/кеш сэмплов, транспонирование и отпускание. Если установлен ffprobe, дополнительно проверяется декодирование MP3.

Клавиатура аккордов автоматически подбирает видимый диапазон по всем нотам выбранного обращения, добавляя крайние белые клавиши для ориентации. Все ноты подсвечены; названия с октавами показаны на клавишах и в строке сразу под ними. На телефоне выбор аккорда прокручивает клавиатуру в поле зрения. Проверка покрывает все 168 аккордов × три положения.
